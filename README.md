# 🤖 Social Robotics: Social-Affective Filter (SAF)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![Platform: macOS / Linux](https://img.shields.io/badge/platform-macOS%20%7C%20Linux-lightgrey.svg)](https://github.com/yelouis/social_robotics)

**Social Robotics** is an extensible data processing engine designed to extract social-affective metadata from large-scale egocentric (first-person) video datasets. By analyzing human reactions, gaze, and prosody in real-world interactions, we aim to build the foundational data required for the next generation of socially-aware robots.

---

## 💡 The Thesis: The Robotic Social Flywheel

At its core, this project is driven by the hypothesis that **we can build a flywheel effect for robotics by learning to interpret human emotions toward the actions a robot performs in real-time.**

1.  **Interpretation**: Developing the ability for robots to "read the room"—understanding whether a human is startled, engaged, or approving of a specific maneuver.
2.  **Reward Signals**: Human emotional responses (e.g., a flinch, a nod, or a change in vocal tone) serve as natural, high-fidelity reward signals.
3.  **Real-Time Learning**: By using these affective signals as feedback, robots can refine their trajectories and behaviors in real-time, leading to safer and more intuitive human-robot interaction (HRI).

The dataset generated by this pipeline—a massive, "dehydrated" collection of social metadata—serves as the primary training and evaluation engine for this vision.

## 🏗️ Pipeline Architecture

The SAF pipeline is built for scale and extensibility, processing Terabytes of video from sources like **Ego4D, EPIC-KITCHENS, Charades-Ego, and EgoProceL**.

### 1. Dataset Acquisition
Automated ingestion of raw egocentric video sources. Due to licensing, we maintain a "Download-Filter-Discard" strategy, only persisting what is necessary for metadata extraction.

### 1a. Synthetic True-Positive Generation
A small, controlled corpus of synthetic egocentric videos with a guaranteed bystander reaction, generated locally via **Wan2.1-T2V** (or small-tier fallback) running on the host's GPU/MPS backend. The clips are rendered **once in a standalone step** and saved to the Extreme SSD; each E2E run **references the saved clips** (via the registry) rather than regenerating them, and a toggle (`SAF_RUN_SYNTHETIC_QA`, default on) selects whether this QA check runs on a given pass. We maintain 1 to 3 synthetic videos in total (regardless of the Ego4D slice size). These videos are filter-QA fixtures only — they are tagged `dataset: "synthetic_validation"`, exercised through Layer 02 to verify the social-presence gates are still detecting true positives, and explicitly gated out of every Layer 03 module and the dehydrated export.

### 2. Filtering & Task Labeling
We strictly filter for "Socially Relevant" moments:
-   **Social Presence**: Videos must contain at least one bystander (excluding the POV actor).
-   **Task Context**: Videos are labeled by the task being performed (using VLMs like Qwen2.5-VL and Moondream) and centered around a "Task Climax"—the moment of highest kinetic or cognitive intensity.

### 3. Social Feature Layers
The heart of the project. Independent modules analyze the filtered video chunks to extract specific social signals:

| Layer ID | Name | Focus | Model / Technique |
| :--- | :--- | :--- | :--- |
| **03a** | [**Attention**](https://huggingface.co/datasets/louisye/social-robotics-attention) | Gaze tracking & engagement scores | L2CS-Net |
| **03b** | [**Reasonable Emotion**](https://huggingface.co/datasets/louisye/social-robotics-reasonable-emotion) | Context-aware emotional analysis | HSEmotion-PyTorch / Gemma 4 |
| **03c** | [**Acoustic Prosody**](https://huggingface.co/datasets/louisye/social-robotics-acoustic-prosody) | Non-verbal vocal cues & tone | emotion2vec+ / SenseVoice |
| **03d** | [**Proxemic Kinematics**](https://huggingface.co/datasets/louisye/social-robotics-proxemic-kinematics) | Relative depth & physical spacing | Depth Anything V1-Large + SAM ViT-Huge |
| **03e** | [**Affirmation Gesture**](https://huggingface.co/datasets/louisye/social-robotics-affirmation-gesture) | Head nodding & shaking detection | SciPy / Signal Processing |
| **03f** | [**Motor Resonance**](https://huggingface.co/datasets/louisye/social-robotics-motor-resonance) | Sympathetic flinch & startle detection | YOLOv8-pose |

### 4. Dehydrated Export
The final output is a **Dehydrated Social Metadata Dataset**. We never export raw pixels. Instead, we provide:
-   **Identifying Metadata**: Rehydration instructions for original video sources.
-   **Social Signals**: The exact time-series data of gaze, prosody, and emotion derived by our layers.

The processed datasets are published and hosted on Hugging Face:
-   📊 [louisye/social-robotics-attention](https://huggingface.co/datasets/louisye/social-robotics-attention) (Layer 03a)
-   📊 [louisye/social-robotics-reasonable-emotion](https://huggingface.co/datasets/louisye/social-robotics-reasonable-emotion) (Layer 03b)
-   📊 [louisye/social-robotics-acoustic-prosody](https://huggingface.co/datasets/louisye/social-robotics-acoustic-prosody) (Layer 03c)
-   📊 [louisye/social-robotics-proxemic-kinematics](https://huggingface.co/datasets/louisye/social-robotics-proxemic-kinematics) (Layer 03d)
-   📊 [louisye/social-robotics-affirmation-gesture](https://huggingface.co/datasets/louisye/social-robotics-affirmation-gesture) (Layer 03e)
-   📊 [louisye/social-robotics-motor-resonance](https://huggingface.co/datasets/louisye/social-robotics-motor-resonance) (Layer 03f)
