# Layer 03d (Proxemic Kinematics) — 50-Clip Smell Test

**Date**: June 9, 2026
**Goal**: Validate the 03d Proxemic Kinematics pipeline (bbox-scale delta + Depth-Anything/SAM depth delta → approach/avoidance vector) on 50 filtered clips, following the 03a/03b/03c smell-test pattern.
**Host**: Mac Studio (M4 Max, 64 GB), MPS. Models (medium tier): `LiheYoung/depth-anything-large-hf` + `facebook/sam-vit-huge`, downloaded on first init to the Extreme SSD HF cache.

## Sample
The same 50-clip manifest as the 03b/03c smell tests (climax metadata already populated → zero added climax cost). Runner: `tools/run_03d_50.py`.

## 1. The 0/50 is structural, not a model failure
`_calculate_bbox_scale_delta` / `_calculate_depth_delta` require **≥ 2 bystander detections strictly inside `task_reaction_window_sec`**. Two geometry facts make that impossible on this corpus:
1. **Cadence**: Node-02 emits bystander detections at a median **6.0 s** spacing (1/3 FPS sampling, sparser after filtering), while reaction windows are **2.0 s** wide → a window holds **at most one** detection, ever. 0/59 tasks met the ≥2 precondition.
2. **Anchoring**: windows are anchored to the *wearer's* optical-flow climax; the nearest bystander detection sits a median **6.8 s** away — the exact wearer-vs-bystander mismatch 03b fixed (03b Resolved #2), which 03d never received.

So 03d never reached its expensive path: depth+SAM ran on zero production frames, which is also why the run took only 3 minutes.

## 2. The mechanics work — proven by probe + visual spot-check
Bypassing the window geometry (spanning each bystander's contiguous detection run near the climax), **4/4 probed clips produced real proxemic vectors**, e.g. `044a7a23` "Attending religious activity": bbox **+26.7 %**, depth-slope +0.0008, vector **+0.21** (Neutral). Visual spot-check (`frames/depth_spotcheck_*.jpg`, clip `044a7a23`): Depth-Anything cleanly silhouettes the bystander (bright = close vs dark background), and the median bystander depth **tracks proximity — 0.13 → 0.28 → 0.12** as the person approaches then recedes. The vector math, depth model, and flow-noise gate are all functional; only the windowing starves them.

## 3. Exemplars (smell-test pattern)
- **Highest / lowest scoring**: **none exist** — 0/50 scored in the production configuration. From the probe: highest = `044a7a23` (+0.21, mild approach), lowest = `0c163d16` (−0.13, mild retreat); both classify Neutral under the ±0.3 threshold, which is plausible for ordinary household/work clips with no dramatic lunge/recoil.
- **Failed to score (representative of all 50)**: `630bd4ba` "Hiking" — 60 bystander detections in the clip, **1** inside the 2 s window → sentinel. Same story for every clip.

## 4. Bonus finding — SAM is silently dead on MPS
Every SAM call fails with `Cannot convert a MPS Tensor to float64 dtype` (the `SamProcessor` emits float64 `input_boxes`/`original_sizes`); the except clause silently falls back to **raw-bbox depth medians**. So on the primary host the documented "bbox-prompted SAM instance masking" never executes, while the 2.5 GB `sam-vit-huge` loads at init as dead weight. The spot-check frame `depth_spotcheck_2_t237.jpg` shows why this matters: the bbox spans a dark doorway behind the bystander, diluting the median. This is the same silent-degradation pattern eliminated in 03b (mock emotions) and 03c (fail-fast deps).

2. **Issue 2 — SAM MPS float64 crash → silent bbox fallback**: single-option dtype fix (cast processor outputs to float32 + loud one-time warning).

## Verdict
- **03d's computational core is sound** (depth, masking-fallback, vector math, noise gate) — verified by probe and visual spot-check.
- **Its windowing contract makes production yield structurally zero** on Node-02 data: detections every ~6 s cannot satisfy "≥2 inside a 2 s window."
- **SAM precision is silently absent on MPS** — must fail loudly or be fixed (trivial dtype cast).
- No further scaling work is warranted until Issue 1's selection lands; the layer is currently cheap *because* it never does its real work.
